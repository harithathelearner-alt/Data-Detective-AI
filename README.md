# 🔎 Data Detective AI

An AI-powered retail sales analysis and investigation tool built with Python, Pandas, Streamlit, and Google Gemini.

Data Detective AI helps users explore retail sales data, identify data-quality issues, detect unusual sales records, visualize business performance, and generate AI-powered business insights.

---

## 🚀 Features

- 📂 CSV dataset analysis
- 🧹 Data quality checking
- 🔍 Missing-value and duplicate detection
- 📊 Sales performance analysis
- 🌍 Region-wise sales analysis
- 📦 Category-wise sales analysis
- 📈 Monthly sales analysis
- 🚨 Sales anomaly detection
- 🤖 Google Gemini AI business analysis
- 📝 Automatic AI business report generation
- 🖥️ Interactive Streamlit dashboard

---

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Google Gemini API
- Google GenAI SDK
- Matplotlib
- Jupyter Notebook
- Git & GitHub
